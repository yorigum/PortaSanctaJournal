## ✨ Overview

**Porta Sancta ID** is a mobile application designed to help Catholic pilgrims in Indonesia participate in the Jubilee Year 2025 by visiting designated *Porta Sancta* churches.

The app empowers users to:
- Browse a list of official Porta Sancta churches across Indonesia.
- Mark churches they’ve visited via check-ins.
- View interactive maps and church details.
- Track pilgrimage progress via a digital "Pilgrimage Passport".
- Access daily prayers and reflections.

---

## 🛠️ Tech Stack

- **Kotlin**
- **Jetpack Compose** (UI)
- **MVI Architecture** (Model-View-Intent)
- **Firebase Firestore** (Database & Auth)
- **Google Maps SDK**
- **Hilt** (Dependency Injection)
